# VP-Skin: volume-preserving rigid skinning for articulated 3D Gaussians

AID 836 (3D Computer Vision, IIIT Bangalore) final project, Problem Statement 2.
This is a fork of [GauHuman](https://github.com/skhu101/GauHuman) at commit `732ec0d`, which is our baseline. GauHuman's original README is [README_GauHuman.md](README_GauHuman.md).
GauHuman is under the S-Lab License 1.0 (non-commercial), which this fork keeps.

## Idea
GauHuman skins each Gaussian with LBS: M = Σ w_j R_j, μ' = Mμ + t, Σ' = MΣMᵀ, so every Gaussian's volume scales by |det M|.
For two bones at relative angle θ about **any** axis, with weights (1−w, w), **det M = 1 − 2w(1−w)(1 − cos θ)**. This hits 0 at w = ½, θ = π: the candy-wrapper collapse, per Gaussian (Prop. 1, `tests/test_skinning.py`).

| | What | Where |
|---|---|---|
| C1 | Dual-quaternion skinning of means **and** covariances (rigid, so volume is exact) | `vpskin/skinning.py`, `--skin_mode dqs` |
| C2 | Learned LBS↔DQS blend field β(x), initialised at LBS | `nets/beta_field.py`, `--skin_mode blend` |
| C3 | Isometry and volume penalties at **unseen AMASS poses**; no rendering, no images | `vpskin/regularizers.py`, `--reg_poses amass --lambda_iso --lambda_vol` |
| B1 | Comparator: quaternion-averaged rotations with LBS means (arXiv 2509.11411) | `--skin_mode quatavg` |

`--skin_mode lbs` with no regulariser reproduces GauHuman exactly.

## 1. Environment
**Kaggle:** open the notebook, choose GPU T4, attach the private datasets listed in its first cell, set `MODE`, and run all cells.
**Local Linux / WSL2 (no sudo):** `bash tools/setup_local_env.sh`. This installs micromamba, PyTorch 2.1, CUDA 12.1 nvcc, and builds the CUDA extensions.
**CPU tests only:** `pip install torch numpy scipy opencv-python imageio plyfile pandas matplotlib pytest`, then `python -m pytest -q tests`.

## 3. Experiments
```bash
bash tools/smoke_gpu.sh                                   # whole pipeline on mock SMPL + fake AMASS (no licensed data)
python tools/run_experiments.py --sweep                   # lambda / k sensitivity, synthetic validation split only
python tools/run_experiments.py --datasets synthetic zju ps --variants all
python tools/run_experiments.py --datasets zju --variants B0 A6 --seeds 0 1 2
python tools/aggregate.py                                 # results/tables.md, tables.tex, figures/
```

| Protocol | Split | Metric |
|---|---|---|
| E1 ZJU novel view | GauHuman's (train view 4, frames 0–495 step 5; test 22 views × 17 frames) | PSNR / SSIM / LPIPS-VGG ×1000 (GauHuman code) |
| E2 People-Snapshot novel pose | 3DGS-Avatar's | same |
| E3 ZJU novel pose | frames after the training range (our extension) | same |
| E4 synthetic 3D GT | unseen AMASS motions, 8 orbit views | PSNR; Chamfer (cm), overall and within 10 cm of joints |
| E5 unseen motions | held-out AMASS (ACCAD, BMLmovi) | neighbour drift (k = 16), per-part volume ratio, hole rate, FPS |
| E6 twist / bend | elbow, knee and shoulder sweeps | mean \|det M\| in the joint region vs Prop. 1 |

Every step appends peak VRAM, wall-clock and GPU-hours to `results/runs.csv`.

**Baseline target** (GauHuman Table 1, ZJU average): PSNR 31.34, SSIM 0.965, LPIPS\* 30.51.
